# Allstar-City

Allstar-Scape (2008) ported to the Lost City engine, with the revision 377 (May 2006) game data,
played in a web browser with Lost City's web client.

```bash
cd engine
npm install
npm run build
npx tsx src/app.ts
```

Then open `http://localhost:<WEB_PORT>/rs2.cgi`. See `allstar/PORTING.md` and `allstar/CONTRIBUTING.md`.
